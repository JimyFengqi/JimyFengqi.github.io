说明：原版是 PHP + SQLite 接口，依赖服务器执行 PHP；本站为 GitHub Pages 静态托管，无法运行 PHP。

因此改造为纯前端静态版：数据库已导出为 acgimg.json，由浏览器随机抽取一条，等价于原来的随机 API。

以 JSON 方式获取数据：

fetch('/acg/acgimg.json').then(r => r.json())

返回的每条记录字段：

{
    "id":1,
    "url":"https://...", # 原始图片地址
    "width":1920,
    "height":1080
}
